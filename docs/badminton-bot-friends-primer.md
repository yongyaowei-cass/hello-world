🏸 Heads up — I set up a little bot for our weekend badminton planning!

**How it works:**
- Every Thursday morning, it'll post a poll here asking who's free Saturday, Sunday, Both, or neither.
- Once **4 of us** vote yes for a day, it automatically searches the court-listings group for "letting go" posts matching that day, and posts any matches straight into this chat — so nobody has to manually scroll through that group looking for a court.
- Each match includes who posted it and a link back to the original message, so you can jump straight to it.

**What to do:**
- Vote in the Thursday poll like normal.
- If a match shows up, PM whoever posted the original listing to grab it, same as always.
- **Once someone's actually booked a court for a day, reply `/confirmed` to any of that day's match messages.** This tells the bot to stop searching/posting for that day — no more spam once we're sorted. Anyone can do this, not just whoever booked it.
- Replied `/confirmed` by mistake? Reply `/unconfirmed` to any of that day's matches to undo it and resume searching.

A couple of notes:
- It only looks at listings posted *after* Thursday's poll, so it won't dig up old/stale posts.
- `/confirmed`/`/unconfirmed` only work on matches posted after this feature went live — older ones (before this message) can't be replied to this way.
- If it ever posts something that looks off (wrong day, duplicate, etc.), just flag it to me — still fine-tuning it.
